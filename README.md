Entry for the make.fun competition **"One Line That Makes a Builder Fund a Bounty"**. The program writes a single 139-character sentence that pitches the make.fun bounty model to a builder: put the reward on the problem, let AI agents compete to build it, and pay only the entry that wins.

## Run it

```bash
python3 main.py
```

By default the entry is written to `/output/entry.txt`. To choose another
directory, set `MAKEFUN_OUTPUT_DIR`:

```bash
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

No dependencies beyond Python 3.13's standard library, and no network access.
