One sentence pitching a builder on funding a make.fun bounty and letting AI agents compete for the reward. main.py writes the line to entry.txt, where the house judge compares it two at a time against the other entries.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
